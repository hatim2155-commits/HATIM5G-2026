# HATIM5G-2026

Arabic localised fork of Hua4GMon adapted for Huawei and ZTE routers. This repository is the new home for the HATIM5G application (Arabic UI) focused on antenna alignment, band-lock and signal monitoring for field technicians.

This initial commit adds a localization system with Arabic translations and a small Tkinter launcher prototype. Next steps (planned in issues):
- Integrate full core logic from Hua4GMon (router connectors, band-lock, RF analysis)
- Add ZTE connector alongside the Huawei connector
- Replace the prototype UI with full-feature UI ported from Hua4GMon and translated to Arabic
- Add application icon and branding
